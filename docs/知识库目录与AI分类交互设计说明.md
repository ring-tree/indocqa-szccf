| 项目 | 内容 |
|---|---|
| 文档版本 | v1.0 |
| 编制日期 | 2026-11-10 |
| 适用页面 | 文档管理页、问答页检索范围、上传预检卡片 |

| 阅读对象 | 前端开发、后端开发、测试、产品 |

---

## 1. 设计原则

1. **空间可感知**：目录层级、当前位置、可放置目标必须同时可见；
2. **操作可逆**：任何移动都能在 8 秒内撤销，超时也有明确恢复路径；
3. **危险动作前置拦截**：非法目标不进入确认流程，不产生网络请求；
4. **AI 只建议、不替代**：AI 永不自动写入，必须用户确认；
5. **降级不阻塞**：AI 超时/不可用时，手动路径始终可用；
6. **键鼠与触屏等价**：拖拽不是唯一入口。

## 2. 术语与状态定义

| 术语 | 定义 |
|---|---|
| 目录面板 | 文档管理页左侧的目录树区域 |

| 合法目标 | 非自身、非子目录、非相同目录、有写权限、存在的目录 |

| 路径选择器 | 入库/移动时选择目录的树形弹窗 |

尺寸：目录面板 240–280px（可拖拽调宽，沿用现有侧栏能力）；表格区域自适应，横向滚动阈值 900px。

### 4.2 平板（768–1023px）

- 目录面板固定 220px，可折叠为图标条；
- 表格允许横向滚动；
- 拖拽保留，但目标节点最小高度 40px。

### 4.3 移动端（<768px）

- 目录面板变为左侧抽屉，默认关闭；
- **禁用拖拽**，每行操作菜单提供"移动到…"；
- AI 面板为全屏底部抽屉；
- 路径选择器为全屏树 + 底部确认栏。

## 5. 目录树组件规范

### 5.1 节点结构

```
[展开箭头] [目录图标] 目录名称                  [文档数]
```

- 缩进：每级 16px，首级 8px；
- 节点高度：桌面 32px，移动端 44px；
- 文档数：右对齐，12px，弱化色 `--muted`；
- 完整路径通过 `title` 与悬停浮层展示，避免同名末级目录混淆。

### 5.2 状态

| 状态 | 视觉 | 触发 |
|---|---|---|
| default | 透明背景，`--muted` 文字 | 默认 |
| hover | `--surface-2` 背景 | 指针悬停 |
| active（当前筛选） | `--brand-soft` 背景，`--brand-ink` 文字，600 字重 | 点击节点 |
| focus | 2px `--brand` 外描边 | 键盘聚焦 |
| dragging-source | 不适用（文档行） | — |
| drop-target | `--brand-soft` 背景 + 2px `--brand` 内描边 + 尾部"移入"标签 | 合法目标悬停 |
| drop-invalid | 2px `--danger` 内描边 + not-allowed 光标 | 非法目标悬停 |
| disabled | 40% 透明度，不可点击 | 无权限/只读 |
| "全部文档" | 无展开箭头、无拖放反馈 | 视图入口 |

### 5.3 交互

- 单击：筛选该目录子树；
- 双击：重命名（仅管理员，P1）；
- 右键：菜单项 `新建子目录 / 重命名 / 删除 / 移动到… / 复制路径`；
- 键盘：`↑/↓` 移动焦点，`→` 展开，`←` 折叠，`Enter` 选中，`Delete` 删除（二次确认），`M` 移动到…；
- 搜索：输入关键字后仅显示命中节点及其祖先，命中词高亮；清空恢复原树。

### 5.4 空状态

- 无目录：显示"还没有目录。上传文档时会自动创建，或点击 + 新建。"
- 搜索无结果："没有匹配的目录。"

## 6. 拖拽交互规范

### 6.1 拖拽启动

| 项 | 规则 |
|---|---|
| 拖拽源 | 文档表格行（不含复选框、下拉框、按钮区域） |
| 启动阈值 | 指针按下后移动 ≥4px |
| 拖拽浮层 | 280×48px 卡片：文件图标 + 文件名（多选时"N 份文档"） |
| 源行反馈 | 透明度 40% |
| 拖拽期间 | 禁止文本选择；`body` 设置 `cursor: grabbing` |
| 禁止拖拽 | 文档处理中、无权限、移动端 |

### 6.2 放置区视觉反馈

**第一层：目录面板整体高亮（明确可交互范围）**

- 面板边框改为 `2px dashed var(--brand)`；
- 面板背景叠加 `var(--brand)` 8% 透明度；
- 面板标题由"目录"变为"**拖到目录中以移动**"；
- 面板内出现一行提示："释放到目标目录，Esc 取消"。

**第二层：目标目录高亮（明确具体落点）**

```
┌ 拖到目录中以移动 ─────────────┐
│ 全部文档                       │  ← 无反馈
│ ▾ 设备手册                     │
│   ├ 螺杆空压机          [移入] │  ← 合法目标
│   └ 无油空压机                 │
│ ▸ 行业标准                     │
└────────────────────────────────┘
```

- 合法：`--brand-soft` 背景 + 2px `--brand` 内描边 + 右侧"移入"标签（12px，`--brand-ink`）；
- 非法：2px `--danger` 内描边，光标 `not-allowed`，悬停 300ms 后显示提示"不能移动到自身或其子目录"；
- 相同目录：按非法处理，提示"文档已在该目录"。

### 6.3 合法目标判定

| 目标 | 合法性 | 说明 |
|---|---|---|
| 普通目录节点 | 合法 | 非自身、非子目录、有写权限、存在 |
| 自身所在目录 | 非法 | 提示"已在该目录" |
| 自身子目录 | 非法 | 提示"不能移动到子目录"（文档无子树，仅防未来扩展） |
| "全部文档" | 非法 | 它是视图入口，不是目录 |
| 文档行/表头/空白区 | 非法 | 不出现任何放置反馈 |
| 已删除/无权限目录 | 非法 | 提前从树中移除/置灰 |

### 6.4 辅助行为

| 行为 | 规则 |
|---|---|
| 自动展开 | 悬停折叠目录 600ms 后展开；离开 200ms 未返回则取消 |
| 边缘滚动 | 指针距面板上/下边缘 <40px 时，每帧滚动 8px，最大 12px |
| Esc 取消 | 立即结束拖拽，不做任何变更 |
| 释放到非法区 | 浮层 200ms 回弹动画，无 Toast（避免噪音） |
| 多选拖拽 | 拖动任一选中行 → 移动全部选中；拖动未选中行 → 仅移动该行并清空其他选择 |

### 6.5 拖拽状态机

```
idle
  └─ pointerdown(行) → pending
        └─ move ≥4px → dragging
              ├─ hover 合法目录 → dragging-valid
              ├─ hover 非法目录 → dragging-invalid
              ├─ Esc → idle
              └─ release
                    ├─ 非法 → idle（回弹）
                    └─ 合法 → confirming
                          ├─ 取消 → idle
                          └─ 确认 → applying
                                ├─ 成功 → success（Toast + 撤销）
                                └─ 失败 → error（回滚 + 重试）
```

### 6.6 键盘与触屏替代

- 文档行聚焦后按 `M` 或操作菜单"移动到…"打开路径选择器；
- 路径选择器与目录树同构，支持搜索、展开、确认；
- 移动端行操作菜单固定包含"移动到…"，不提供拖拽。

## 7. 二次确认与撤销

### 7.1 确认弹窗

```
┌ 移动 3 份文档？ ─────────────────────────────┐
│                                              │
│ 源目录：  设备手册/螺杆空压机                │
│ 目标目录：行业标准/压缩空气系统              │
│                                              │
│ 文件：螺杆手册.pdf、无油说明.pdf、           │
│       能源部手册.pdf 等 3 份                 │
│                                              │
│ 移动后 8 秒内可撤销。                        │
│                                              │
│                        [取消]  [确认移动]    │
└──────────────────────────────────────────────┘
```

| 项 | 规则 |
|---|---|
| 标题 | `移动 {N} 份文档？` |
| 文件列表 | 最多展示 3 个文件名，超出显示"等 N 份" |
| 默认焦点 | "取消"按钮（防止误按 Enter） |
| 键盘 | Enter 确认、Esc 取消、Tab 循环 |
| 加载态 | 按钮变"移动中…"并禁用，弹窗不可关闭 |
| 失败态 | 弹窗内红字错误 + "重试"；不关闭弹窗 |
| 遮罩点击 | 不关闭（防止误触丢失上下文） |

### 7.2 误操作拦截

| 场景 | 拦截时机 | 反馈 |
|---|---|---|
| 拖到自身/子目录/相同目录 | 拖拽悬停 | 非法态，不进入确认 |
| 拖到"全部文档"/空白区 | 拖拽悬停 | 无放置反馈 |
| 目标目录已删除 | 确认时服务端校验 | 40402 → 弹窗内提示并刷新树 |
| 知识库被占用 | 提交时 | 40903 → Toast"知识库正在被其他进程写入，请稍后重试" |
| 无权限 | 树节点置灰 | 不可悬停高亮 |
| 重复提交 | 提交中禁用按钮 | 只发一次请求 |

### 7.3 撤销提示条

```
┌────────────────────────────────────────────────────────────┐
│ 已移动 3 份文档到「行业标准/压缩空气系统」      [撤销]  8s │
└────────────────────────────────────────────────────────────┘
```

| 项 | 规则 |
|---|---|
| 位置 | 页面底部居中，距底 24px |
| 宽度 | `min(480px, calc(100vw - 32px))` |
| 时长 | 8 秒；悬停暂停倒计时 |
| 撤销 | 调用 `POST /api/kb/moves/{operationId}/undo`；按钮变"正在撤销…" |
| 成功 | 提示条变"已撤销"，2 秒后消失，列表与树同步刷新 |
| 失败 | 提示"撤销失败：{原因}，请手动移回" |
| 覆盖规则 | 新的移动操作替换当前提示条，只保留最近一次撤销 |

### 7.4 操作记录（P2）

- 入口：文档管理页右上角"操作记录"；
- 字段：时间、操作人、动作、数量、源目录、目标目录、结果、撤销状态；
- 支持按时间/操作人筛选；保留 30 天。

## 8. AI 辅助分类控件

### 8.1 触发入口

| 入口 | 位置 | 适用 |
|---|---|---|
| A | 上传预检卡片："AI 推荐目录"按钮 | 入库前 |

**触发时机**：必须在文档解析完成、拿到摘要后进行；解析失败或内容重复时不提供。

```
┌ AI 推荐目录 ─────────────────────────────── [×] ┐

│                                                  │

│                                                  │

└──────────────────────────────────────────────────┘
```

- 阶段顺序固定；完成打勾，当前旋转，未开始为空心；
- 8 秒未完成：切换为"规则推荐"结果，并提示"AI 响应超时，已使用规则推荐"；
- 无规则结果：进入空状态。

### 8.4 候选卡片规范

| 元素 | 规则 |
|---|---|
| 单选 | 默认选中 Top1；切换即更新"采纳"目标 |
| 路径 | 完整路径，超长省略中间段，悬停显示全路径 |
| 置信度 | 高 ≥80%（`--success`）、中 60–79%（`--warning`）、低 <60%（`--muted`） |
| 依据 | ≤40 字，说明命中的规则/语义信号 |
| 证据 | 最多 3 个关键词/章节，供用户判断 |
| 相近提示 | Top1-Top2 <5% 时，在 Top1 卡片显示"与第二候选接近，请确认" |

### 8.5 操作

| 操作 | 行为 |
|---|---|
| 采纳并移动 | 打开移动确认弹窗（目标=所选候选），确认后执行移动，Toast 可撤销 |
| 调整目录 | 打开路径选择器；确认后把所选路径作为"手动调整"候选，仍需点击"采纳并移动" |
| 驳回 | 记录负反馈，关闭面板，Toast"已驳回，感谢反馈" |
| 关闭 × / Esc | 视为放弃，不记录反馈，不产生变更 |
| 重试 | 错误态显示"重新分析"，重新走完整流程 |

### 8.6 空状态与错误态

**空状态（无候选 ≥60%）**

```
┌ AI 推荐目录 ─────────────────────────────── [×] ┐
│ 暂无可靠推荐（最高置信度 48%）                   │
│ 这份文档的主题不够集中，建议手动选择目录。       │
│                                                  │
│ [手动选择目录]              [重新分析]           │
└──────────────────────────────────────────────────┘
```

**错误态**

```
AI 推荐暂不可用（原因：模型服务超时）
[重试] [手动选择目录]
```

- 手动选择始终可用，不阻塞入库；
- 错误不写入任何分类结果。

## 9. 入库路径选择

### 9.1 预检卡片布局

```
┌ 螺杆式空压机操作手册.pdf                    预检通过 ┐
│ 48 页 · 预计 106 块 · 43 个表格 · 中文              │
│                                                    │
│ 入库目录                                            │
│ 当前：设备手册/螺杆空压机            [更改]         │
│ [手动选择] [AI 推荐]                                │
│                                                    │
│ AI 推荐：设备手册/螺杆空压机 92%  [采用]            │
│                                                    │
│                              [放弃] [确认入库]      │
└────────────────────────────────────────────────────┘
```

### 9.2 手动选择

- 点击"更改"打开路径选择器；
- 选择器包含搜索框、目录树、"新建目录"按钮；
- 确认后回显完整路径；路径不存在时提示"目录已被删除，请重新选择"；
- 默认值：当前左侧选中的目录；未选中时为"未分类"。

### 9.3 AI 推荐

- 点击"AI 推荐"页签触发，展示加载 → 候选列表 → 采用；
- 候选以单选列表展示，默认不改变当前路径；
- 点击"采用"后当前路径更新为推荐目录，并在下方显示"已采用 AI 推荐"；
- 用户随后手动更改路径时，提示"已切换为手动选择"，AI 结果保留可再次采用；
- 多文件上传：每个文件独立路径行；顶部提供"全部采用 AI 推荐"（P1），逐文件分析时显示"AI 分析 3/8"。

### 9.4 用户选择优先级

```
用户手动选择 > AI 推荐 > 当前目录 > 未分类
```

- AI 结果**永不覆盖**用户已手动选择的路径；
- 用户未选择且 AI 置信度 ≥80% 时，路径行显示"建议：X（92%）"，但不自动填入；
- 用户未选择且 AI 置信度 <60% 时，只显示"未找到可靠推荐"。

### 9.5 冲突与异常

| 场景 | 处理 |
|---|---|
| 内容重复 | 路径行禁用，显示"内容已存在，将跳过" |
| 预检拒绝 | 隐藏路径行，仅保留"移除" |
| 目标目录被删除 | 内联提示 + 打开选择器重选 |
| 新建目录重名 | 合并到已有目录并提示 |
| 入库中 | 路径行只读，按钮显示"入库中…" |

## 11. 响应式与无障碍

### 11.1 响应式

| 断点 | 目录树 | 拖拽 | AI 面板 | 路径选择 |
|---|---|---|---|---|
| ≥1024 | 固定 240–280px | 支持 | 560px 居中弹层 | 480px 弹窗 |
| 768–1023 | 220px 可折叠 | 支持 | 560px 弹层 | 480px 弹窗 |
| <768 | 左侧抽屉 | 禁用 | 全屏底部抽屉 | 全屏 |

### 11.2 无障碍

- 目录节点 `role="treeitem"`，`aria-expanded`、`aria-level`、`aria-selected`；
- 拖拽提供 `aria-describedby` 说明："按 M 键移动到其他目录"；
- 移动结果通过 `aria-live="polite"` 播报；
- 确认弹窗焦点陷阱，Esc 关闭，关闭后焦点回到触发元素；
- 所有颜色状态同时有图标/文字，不仅依赖颜色；
- 触控目标最小 44×44px。
