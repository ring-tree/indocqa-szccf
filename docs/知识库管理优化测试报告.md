## 5. 未覆盖项与说明

1. **原生拖拽**：浏览器自动化无法可靠合成 HTML5 DragEvent（合成事件未触发 React 业务逻辑），已通过"移动"按钮完整验证确认/校验/取消链路；拖拽代码使用标准 `draggable + onDragStart/onDragOver/onDrop`，建议上线前用真实鼠标执行一次人工回归（拖入合法目录、相同目录、空白区、折叠目录自动展开）。
2. **无模型状态的前端置灰**：通过代码与后端 40904 门禁验证，未在浏览器中切换无模型实例（会与当前 Chroma 单写锁冲突）。按钮 `disabled` + `title="无可用模型"` 已实现。
3. **网络中断/任务线程异常**：入库任务失败路径在代码中回传 error 并保留待入库卡片；未做断网注入测试。
4. **大批量性能**：当前 4 文档/414 块；批量分类逐篇进行，文档上千时需改为服务端后台任务（已列入后续优化）。

## 6. 验收判定

- AI 批量分类：入口、独立模型、全量范围、确认/进度/统计、无模型禁用均符合需求；

- 入库进度：百分比、文档数、状态文本实时更新，异常可恢复；
- 范围树：目录层级、父子联动、半选状态、多选并集检索均符合（仅移除提示语句）；
- 移动边界：已在目标目录不再失败，统计明确；撤销提示可关闭；
- 无回归：后端 88 项测试、前端构建与既有问答/入库/目录功能正常。

结论：**功能符合预期，可进入人工拖拽回归与发布评审**。
